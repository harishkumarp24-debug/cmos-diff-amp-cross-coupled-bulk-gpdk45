# cmos-diff-amp-cross-coupled-bulk-gpdk45
Research-paper-inspired design of a fully differential CMOS amplifier with cross-coupled bulk active load using Cadence Virtuoso and GPDK45 (45 nm). Includes transistor sizing optimization, DC/AC/transient, noise, Monte Carlo and PVT analyses, full-custom layout, DRC/LVS verification, RC parasitic extraction, and GDS generation.
